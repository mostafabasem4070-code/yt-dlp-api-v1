# 🚀 نظام استخراج الروابط المباشرة لليوتيوب (YouTube Direct Links & Cookie Hub API)

واجهة برمجية (RESTful API) متطورة وسريعة مبنية بلغة Python و FastAPI ومكتبة `yt-dlp`، صُممت خصيصاً للعمل على منصة **Railway** أو **Docker** بأعلى كفاءة وأمان، وتتيح لمنصتك (مثل Laravel) إرسال رابط فيديو يوتيوب والحصول على ملف `JSON` منظم يحتوي على تفاصيل الفيديو وروابط البث والتحميل المباشرة المؤقتة لجميع الجودات (بما في ذلك البث المقسم `10MB Chunks` ودمج الفيديوهات الفائقة 1080p و 4K لحظياً عبر FFmpeg).

---

## 📂 هيكل المشروع (Project Structure)

```text
├── main.py                # خادم FastAPI، نقاط النهاية، توحيد الطلبات (SingleFlight)، ولوحة التحكم
├── stream_service.py      # محرك البث المقسم 10MB Chunks، حماية SSRF، ودمج FFmpeg اللحظي
├── health_monitor.py      # مركز مراقبة صحة وتشخيص كافة مكونات النظام والموارد الحية
├── updater_service.py     # خدمة التحديث التلقائي الدوري لـ yt-dlp وتنظيف قاعدة البيانات
├── youtube_service.py     # محرك الاستخراج المتعدد المراحل وحل التحديات البرمجية
├── cookie_manager.py      # مدير الكوكيز الذكي وتدوير الحسابات المتعددة (Cookie Pool)
├── google_auth_service.py # متصفح Playwright التفاعلي عن بُعد وتوليد PO Token تلقائياً
├── security_manager.py    # جدار حماية الدومينات، مفاتيح API، وإشعارات Telegram/Webhook
├── stats_manager.py       # محرك إحصائيات الاستخراج (SQLite WAL) مع التنظيف التلقائي
├── static/
│   └── dashboard.html     # واجهة التحكم التفاعلية ومركز المراقبة الشامل
├── requirements.txt       # مكتبات بايثون المطلوبة
├── Dockerfile             # ملف تشغيل الحاوية لـ Railway (يشمل ffmpeg و Deno و Node 20 LTS)
└── railway.json           # إعدادات النشر على منصة Railway
```

## ✨ أبرز المميزات والتحسينات المعمارية

1. **تعدد استراتيجيات الاستخراج (5-Stage Smart Fallback)**:
   - يجرب الكوكيز النشطة (مع تدوير تلقائي من مسبح الكوكيز `Cookie Pool`)، ثم يتراجع تلقائياً إلى `tv_downgraded`، ثم `android_vr`، ثم `web_embedded`، ثم وضع الزائر القياسي بدون أي تأخير مصطنع.
2. **توحيد الطلبات المتزامنة (SingleFlight Request Deduplication)**:
   - إذا طلب عشرات الطلاب نفس الفيديو في نفس الثانية، يقوم السيرفر باستخراجه مرة واحدة فقط من يوتيوب ويوزع النتيجة على جميع الطلبات المتزامنة في أجزاء من الثانية.
3. **محرك البث السريع المحمي (`/api/stream` & `/api/stream/mux`)**:
   - تقطيع الطلبات إلى شرائح `10MB` لتجاوز خنق السرعة (`Throttling`) مع إعادة استخدام اتصالات الشبكة (`Connection Pooling`) وحماية صارمة ضد ثغرات `SSRF`.
   - دعم دمج مسارات الفيديو عالية الدقة (`1080p / 4K`) مع الصوت لحظياً عبر `/api/stream/mux` باستخدام `FFmpeg` بدون استهلاك مساحة تخزين.
4. **مسبح وتدوير الكوكيز (Multi-Account Cookie Pool)**:
   - إمكانية إضافة عدة حسابات كوكيز والتبديل التلقائي بينها عند انتهاء أو حظر أحد الحسابات.
5. **استخراج تلقائي لـ `PO Token` و `Visitor Data` + تنبيهات Telegram**:
   - توليد `visitor_data` و `po_token` تلقائياً عبر متصفح Chromium المدمج، مع إرسال تنبيهات فورية عبر Telegram أو Webhook عند اقتراب انتهاء الكوكيز.
6. **دعم التخزين الدائم (`DATA_DIR`)**:
   - إمكانية تحديد متغير البيئة `DATA_DIR=/data` لربطه بـ Railway Volume لضمان عدم ضياع الكوكيز أو الإعدادات أو الإحصائيات عند إعادة النشر.

## 💻 طريقة التشغيل محلياً (Local Setup)

1. إنشاء وتفعيل البيئة الافتراضية:
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\activate
   ```
2. تثبيت المتطلبات:
   ```bash
   pip install -r requirements.txt
   ```
3. تشغيل السيرفر:
   ```bash
   uvicorn main:app --reload --port 8000
   ```
4. فتح لوحة التحكم:
   - لوحة التحكم الشاملة: `http://127.0.0.1:8000/dashboard`
   - توثيق Swagger التفاعلي: `http://127.0.0.1:8000/docs`
